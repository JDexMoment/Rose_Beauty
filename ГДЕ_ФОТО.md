# Куда кидать фото — обновлено (с портфолио мастеров)

### Папки уже созданы (все .jpg)
```
public/
  masters/          → фото мастеров (если хочешь локальные вместо Dikidi)
  salon/            → фото интерьера (hero.jpg)
  works/
    kristina/       → 1.jpg, 2.jpg ... 6.jpg  (Кристина)
    olga/           → 1.jpg ... 6.jpg        (Ольга)
    irina/          → 1.jpg ... 6.jpg        (Ирина)
    daria/          → 1.jpg ... 6.jpg        (Дарья)
    viktoria/       → 1.jpg ... 6.jpg        (Виктория)
```

**Важно: расширение ТОЛЬКО .jpg**  
Если у тебя .png / .webp / .heic / .jpeg — переименуй в .jpg (просто поменяй расширение в проводнике, или пересохрани). Код ищет именно `1.jpg`. Так быстрее и без ошибок.

### Шаг 1 — скопируй
Перетащи мышкой в проводнике Windows:
```
public/works/kristina/1.jpg
public/works/kristina/2.jpg
...
public/works/daria/1.jpg
public/salon/hero.jpg  (если хочешь заменить главный баннер)
```

Если фото пока нет — оставь пусто, покажется красивая заглушка с Unsplash.

### Шаг 2 — ничего в коде менять не надо!
Страницы мастеров уже настроены:
- `/masters/kristina` — берёт фото из `public/works/kristina/`
- `/masters/olga` — из `public/works/olga/` и т.д.
Клик по фото — увеличивает.

Если хочешь поменять аватар мастера — открой `src/data/masters.ts` и поменяй поле `avatar`.

### Портфолио на главной
Главная секция «Портфолио» пока показывает общие заглушки. После того как добавишь фото в папки мастеров, они автоматически появятся на персональных страницах.

Готово. `npm run dev` сам перезагрузится.
