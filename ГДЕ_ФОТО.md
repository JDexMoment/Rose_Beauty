# Куда кидать фото — за 1 минуту

### Папки уже созданы
```
public/
  masters/  → фото мастеров
  works/    → фото работ (портфолио)
  salon/    → фото интерьера
```

### Шаг 1 — скопируй файлы
Просто перетащи jpg/webp/png в эти папки через проводник Windows.
Пример после:
```
public/masters/kristina.jpg
public/masters/olga.jpg
public/works/work1.jpg
public/salon/hero.jpg
```

### Шаг 2 — поменяй 3 строчки в коде
Открой `src/app/page.tsx` в VS Code (Ctrl+P → page.tsx)

**1. Мастера** — найди `const masters = [` (строка ~27), поменяй:
```js
// было
img: "https://f2.dikidi.net/..."

// стало
img: "/masters/kristina.jpg"
```

**2. Работы** — найди `const works = [` (строка ~115):
```js
// было
"https://images.unsplash.com/..."

// стало
"/works/work1.jpg",
"/works/work2.jpg",
```

**3. Главное фото салона** — найди `photo-1560066984` и замени на `"/salon/hero.jpg"`

Сохрани (Ctrl+S) — сайт сам перезагрузится в браузере.

### Требования к фото
- Квадрат или вертикаль, 800px+, jpg/webp до 1.5МБ
- Не надо переименовывать всё идеально — главное чтобы путь совпал
- Если фото пока нет — оставь ссылки как есть, потом заменишь

Готово. Не надо никуда загружать на хостинг — Next.js сам всё раздаст.
